## 0. 全局执行铁则（所有工作流通用）

1. **每步先验证再下一步**：步骤标"验证"的命令必须实际跑并确认输出，禁止跳过。
2. **失败即停**：任一步骤失败，执行该工作流回滚方案，不带着错误往下走。
3. **付费 API 红线**：凡涉及 LLM/上游调用，一律 `IF_MOCK_UPSTREAM=1` Mock 验证拼装，禁止真实付费（tryingopen 免费上游除外，且需最小调用次数）。
4. **Windows 约束**：禁 `.sh` 脚本；命令链接用 `; if($?) { }`（PowerShell）或 `&&`（bash/WSL）；查可执行文件用 `where.exe`；搜索用内置 `rg`。
5. **不自动提交**：未经用户明确指示不 commit/push/PR；提交前过 `.pre-commit-config.yaml`。
6. **不碰禁区文件**：`.venv/` / `graft/` / `landing/node_modules/` / `可参考的项目/` 不属本项目源码。
7. **已落地项勿重做**：storage 热路径 / 大文件拆分 / agent E2E / litestream / Grafana / 向量检索 / 成本预测 / flaky 根治 —— v8.5.0 均已闭环，本细则不涉及。
